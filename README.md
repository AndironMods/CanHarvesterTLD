# CanHarvesterTLD

A simple mod for **The Long Dark** that makes Recycled Cans harvestable for Scrap Metal.

## Installation

1. **Requirements:**
   - MelonLoader installed for The Long Dark

2. **Install:**
   - Download `CanHarvesterTLD` Mod
   - Place `CanHarvester.dll` in: `...\steamapps\common\TheLongDark\Mods` Folder
   - Launch the game

3. **Done!** The mod loads automatically.

## How It Works

- **Pick up a Recycled Can** from the game world
- **Open your inventory** and select the can
- **Press the ACTIONS button** that appears
- **Harvest the can** to get 1x Scrap Metal

## Features

- Works in any language
- No dependencies - uses internal game references
- Integrates seamlessly with The Long Dark UI

## Uninstall

- Delete `CanHarvester.dll` from the `Mods/` folder
- Restart the game

## Support

This mod only affects Recycled Cans. All other game mechanics remain unchanged.
